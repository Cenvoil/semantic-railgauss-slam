# mask 级语义图生成方案（d 系列 · 2026-09-18）

> 目标：产出**像素级语义 + 实例级掩码**（不只是类级框图），作为 SLAM 语义监督与实例建图的统一输入。
> 前提：官方 OSDaR23 数据绝对正确；深度与语义是后续所有任务的挂载点，必须先打磨、后使用。

## 一、手上的官方资产（能给出什么，给不出什么）

| 官方资产 | 形态 | 能确定 | 局限 |
|---|---|---|---|
| cuboid（LiDAR 系） | 3D 盒 + 位姿 + 尺寸，1977 条 | 车辆/缓冲挡/杆/信号机/行人的**三维位置与体积** | 无轮廓，需投影+精修 |
| poly2d（rgb_highres_center） | 像素级闭合/开放折线，5662 条 | **真正的像素级真值**（灯面、轨道线、部分轮廓） | 只覆盖被标类别 |
| poly3d / vec（LiDAR 系） | 3D 折线 / 点云索引，2877 条 | **轨道带**（stuff 类唯一可靠来源） | 需投影 |
| bbox（各相机流） | 2D 框，9459 条 | 目标存在性与大致位置 | 已知系统性偏移，**不可当掩膜真值** |
| 39 个唯一对象 + UUID | 跨帧一致的对象身份 | **实例 id 天然可跨帧追踪** | 只标了 39 个物体 |
| LiDAR PCD / 伪 GT 深度 | 稠密几何 | 深度不连续 → 掩膜收边依据 | — |

**关键判断**：官方能给出「目标在哪、什么类、哪个实例」，但①没有逐物体像素轮廓；②未标注 stuff（道砟、植被、天空、建筑、地面）。所以**必须**用分割模型补轮廓与 stuff，官方只做硬约束与仲裁者 —— 反过来（模型主导）会丢掉铁路特有类别（接触网杆、道岔、缓冲挡通用模型根本没有）。

## 二、方案总纲：四层融合（官方优先 / SAM2 精修 / 通用模型补洞 / 几何收边）

### L1 官方强约束层（可信度最高）
1. cuboid → 用**官方内参 + 官方外参**（本轮已定轴约定：四元数 xyzw，相机 OpenCV 轴→base 的置换 M=[[0,0,1],[-1,0,0],[0,-1,0]]）投影成 8 顶点，取凸包为**粗掩膜**，同时给出该物体的深度平面（面片深度）。
2. poly2d（closed）直接作为该类掩膜；poly3d/vec 投影出**轨道带**。
3. 每个官方对象 UUID → 实例 id，跨帧天然一致（100 帧）。
4. 深度平面用于 L3 收边与遮挡排序。

### L2 SAM2 像素级精修层（粗掩膜 → 贴合轮廓的像素级掩码）
- **为什么 SAM2**：①训练无关（zero-shot），铁路域外类别照样能切；②支持 **video predictor**，同一 obj_id 跨 100 帧传播，实例 id 与官方 UUID 绑定，天然解决跨帧一致性；③多掩膜 + 稳定性分数可选优。
- prompt 设计：粗掩膜 + 沿物体轴的**多点补充**（细长杆件必须多点，否则 SAM 会顺栅栏延伸 —— v7~v10 三次失败的老坑）+ **负点抑制**（在已知背景/栅栏上加负点）。
- 选优准则：与 official prompt 的 IoU × 稳定性分数 × **深度连续性**（掩膜内深度方差小）三项乘积最大者。
- 遮挡：深度大于该物体平面的像素判为背景，不外推；物体被完全遮挡时该帧不出掩膜（登记不丢弃）。

### L3 未标注 stuff 补全层
- 通用分割模型：**OneFormer / Mask2Former**（Cityscapes + Mapillary 权重）或 SegFormer-B5，只取它可靠的 stuff：sky / vegetation / building / road / terrain，再映射到我们的 29 类表（sky=24 等）。
- 铁路特有 stuff 走**几何规则**（模型给不出）：
  - 道砟/地面：由深度 + 行号透视约束（地平面 d·(v−cy)≈C）+ 轨道带外侧区域确定；
  - 护栏：轨道线平行偏移带；
  - 接触网/承力索：画面顶部细结构（有 poly2d 则用 poly2d）。
- **深度收边**：任何掩膜不得跨越相对深度跳变 >15% 的边界（用深度梯度切断），这是防止掩膜"顺背景延伸"的第二道闸。

### L4 仲裁与输出
优先级：**官方 poly2d / cuboid投影 > SAM2 掩膜 > 通用模型 > 几何规则**（后者不得覆盖前者）。
产出三通道（与原深度 GT 同构，便于 SLAM 加权监督）：
- `semantic_id*.png`：类 id（uint8/uint16）
- `instance_id*.png`：实例 id（uint16，0=无实例，值=官方 UUID 序号）
- `sem_conf*.png`：置信（2=官方强约束 / 1=SAM2 / 0=模型或规则填充）

## 三、为什么不用其它路子
- **纯端到端全景分割模型**：域外类别（接触网杆、道岔、缓冲挡）无标签，模型根本不认识 → 直接判负。
- **只用官方标注**：39 个物体 + 无 stuff，覆盖率不足以训练语义高斯。
- **官方 2D bbox 当掩膜**：已知系统性偏移（近物 60-350px），会污染语义与实例。
- **只用 SAM 无官方约束**：类别无从确定、实例 id 无法跨帧一致、细长杆件必翻车。

## 四、验收门（硬证据，四门齐全才算可挂载）
1. **官方一致性**：与官方 poly2d 逐类 IoU（poly2d 是像素级真值）；bbox 仅作参考。
2. **目检**：帧 0/29/59/99 叠加图（掩膜边界 + 类别名 + 实例 id），前后帧 id 一致性。
3. **统计**：每类像素占比、stuff/thing 覆盖率、无效区占比、跨帧 ID switch 次数。
4. **下游不劣化**：挂到 d 系列 8 帧冒烟，渲染 PSNR / 语义 mIoU 不劣于当前基线。

## 五、阶段与依赖
- **前置（阻塞）**：官方外参自证收尾。本轮已确定四元数顺序 xyzw 与轴置换 M，但残差仍剩 **Δu=-122px / Δv=+303px**，嫌疑是官方强畸变（k1=-0.076, k2=-0.188, **k3=1.78**）未建模 —— 必须先做 undistort 或量化确认，否则 L1 投影粗掩膜会整体偏移。
- S1 官方几何投影粗掩膜（含轨道带）→ 1 天
- S2 SAM2 精修 + video 跨帧传播（需 SAM2 权重，走 ModelScope 镜像）→ 2 天
- S3 stuff 补全（OneFormer/Mask2Former 权重）→ 1 天
- S4 仲裁/收边/三通道输出 → 1 天
- S5 四项验收门 + 交付目检包 → 1 天

## 六、d 系列数据资产挂载约定（深度同此）
